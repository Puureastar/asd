### 其他常见服务：15元起

如您自带硅脂、相变片、风扇、内存等配件或耗材，人工服务费不予减免。仍需进行兼容性评估与安装测试；若因自带配件质量问题导致损坏，责任由客户自行承担。

## 二、客户义务：请务必提前告知

为避免误判、重复拆装或意外损坏，请在送修时主动说明设备已知问题或历史状况：

- 风扇异响、转速异常。
- 键盘按键粘滞、失灵、进液痕迹。
- 曾自行拆机、清灰、更换部件。
- 摔落、进水、挤压、电池鼓包、外壳变形。
- 屏幕坏点、漏液、背光不均等显示问题。
- 系统频繁蓝屏、死机。
- 无法充电、接口异常。
- 其他可能影响维修判断的“暗病”。

> 隐瞒已知缺陷可能导致维修失败、二次损伤或额外费用，此类情况恕不退费或担责。

1. **基础检测：** 维修前进行基础检测并告知设备现状。
2. **风险提醒：** 老旧设备、液金机型等无法 100% 排除意外风险。
3. **继续处理：** 过程中发现新问题，经您同意或提前授权后才继续处理。
4. **数据自保：** 请提前备份数据，维修方不承担任何数据丢失责任。

以下情况不在服务保障范围内：

- 设备老化、进水、摔损、私自改装、使用非原装配件。
- 液金相关服务无任何形式售后保障。
- 因客户未如实告知已有故障或配件导致的问题。
